# Games to build

Each entry: number. `file.html` · best key · Title · Bible refs (fetch the exact text with scripts/check-verses.js --show) · how it plays · suggested Music.theme.
Design each so it is FUN on a phone, tap-first, at least 5 levels with a real ramp, and the player can lose. The mechanics below are starting points; improve them if something clearer or more fun fits the story.
